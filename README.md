## ✨ About This Project

Michael B Isbell Media is the foundational personal brand site for Michael "ZADAN" Isbell — a single-page landing that introduces his media and creative work. Originally built and deployed on WordPress, it was later rebuilt from the ground up in React as Michael's craft evolved into the full digital agency known today as Zathena Ventures.

*   **🎬 Personal Media Brand**: A clean, single-page home for Michael B Isbell's media, creative work, and online presence.
*   **🕰️ A Piece of History**: The very first website Michael deployed — preserved and modernized as the origin story of Zathena Ventures.
*   **🔁 WordPress → React**: Re-engineered from a legacy WordPress site into a fast, modern React single-page application.
*   **📞 Connect**: A simple hub for learning about and getting in touch with Michael B Isbell Media.
*   **📱 Fully Responsive**: A lightweight, mobile-first design that loads fast on any device.
